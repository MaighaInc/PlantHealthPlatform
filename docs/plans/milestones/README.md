# Per-Milestone Plans

> Generated implementation plans for each PHP milestone

Create one plan file per milestone as work begins:

```text
milestones/
├── PHP-01-ros-foundation.md
├── PHP-02-ros-parameters.md
├── PHP-03-virtual-sensors.md
└── ...
```

## Plan Template

Each milestone plan should include:

```markdown
# PHP-NN — Title

## Goal
## Prerequisites (prior milestones)
## Acceptance Criteria
## Architecture Impact
## Files to Create/Modify
## Interfaces
## Tests
## Documentation Updates
## Known Risks
```
